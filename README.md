# MediConnect – SIH 2024 Project

MediConnect is a comprehensive healthcare platform developed for the Smart India Hackathon 2024. It aims to simplify and digitize healthcare access for patients while empowering doctors and hospitals with a modern, connected ecosystem.

## 🚀 Features

- 🔍 Search and discover doctors by specialty, location, or availability
- 📅 Book appointments online
- 💬 Secure teleconsultation via video/audio
- 📄 Manage electronic health records (EHR)
- 🔔 Smart reminders and notifications
- 🏥 Doctor/hospital dashboards

## 🛠️ Tech Stack

### Frontend
- Next.js
- Tailwind CSS
- React Query / SWR
- Socket.io (for real-time)

### Backend
- Django / Django REST Framework
- SQLite
- JWT Authentication
